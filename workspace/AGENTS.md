# AGENTS.md — NotePlanner 知识库工作目录

这是 **NotePlanner**（一款本地 Markdown 笔记应用）的工作目录，同时被当作 agent 的可读写知识库。

## 目录结构（由 NotePlanner 决定，请遵守）

- 顶层文件夹 = **主题**（topic），例如 `工作`、`生活`、`阅读`
- 主题下的二级文件夹 = **笔记集**（collection）
- 任意 `.md` 文件 = **一条笔记**，文件名即标题
- `零散笔记/` = 零散笔记区（未归类知识的默认落点）
- `回收站/` = 回收站，**不要写入**
- 根目录的配置类文件（`AGENTS.md`、`noteplanner.rules.md`、`.yaml`）不会被当成笔记

## 你的职责

1. 回答用户问题时，把有价值的知识点沉淀为笔记（详见 `noteplanner.rules.md`）。
2. 写文件即可，NotePlanner 会通过文件监听自动刷新，无需其它操作。
3. 文件夹 / 文件名避开 `\ / : * ? " < > |` 九个字符。

## 约定

- 读法：顶层文件夹是主题，二级文件夹是笔记集，`.md` 是笔记。
- 写法：在目标路径新建 / 追加 `.md`；未归类内容放 `零散笔记/`。
- 路由与去重规则：以 `noteplanner.rules.md` 为准，每次会话开始读取。
