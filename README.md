# NotePlanner

本地优先的 Markdown 知识管理桌面应用。笔记以 `.md` 文件存于本地 `workspace/` 目录，**数据完全归你所有**，不绑定任何平台。

- 三层组织结构：**主题（L1）→ 笔记集（L2）→ 笔记（L3）**，像文件系统目录树，但为笔记场景优化。
- 克制、专注的界面：珊瑚色（`--accent`）主视觉，Manrope / DM Mono 字体，统一 ease-out 动效。
- Electron 实现，无需浏览器，双击即可启动。

---

## 快速开始

### 方式一：双击启动（推荐）

直接双击项目根目录的 `start.bat`：

1. 脚本会自动把托管版 Node 加入 PATH，并配置 `ELECTRON_MIRROR` 走国内镜像。
2. 若 `node_modules/electron` 不存在，自动 `npm install electron`。
3. 启动主窗口。

> 首次启动若网络访问官方源慢，脚本已默认走 `registry.npmmirror.com` 镜像，一般无需手动干预。

### 方式二：命令行启动

```bash
cd H:\NotePlanner
npm install     # 首次安装依赖（electron）
npm start       # 启动应用
# npm run dev  进入开发模式（带 --dev 参数）
```

### 环境要求

- Windows（已适配；macOS / Linux 理论可用，未专门验证）。
- Node 22+（脚本使用托管版 Node 22.22.2；你本机有 Node 也可）。
- Electron 43（作为 devDependency，由 `start.bat` 或 `npm install` 安装）。

## 本版本实现的功能

### 1. 三栏笔记集视图（核心）

点侧边栏「笔记集」进入。视图由左至右三栏：

- **主题树栏**：展示主题与笔记集的层级树，可新建 / 重命名 / 删除 / 置顶 / 折叠。
- **笔记集栏**：展示当前主题下的**全部**笔记集（每张卡片含其笔记列表，至多 5 条，超出可滚动）。点击卡片即选中该笔记集，点卡片内笔记即载入右侧编辑器。
- **Markdown 栏**：Markdown 编辑器 + 实时预览（「预览 / 编辑」按钮切换）。

**三栏各自独立滚动**：每栏高度锁定视口，内容超出时仅在该栏内部滚轮滚动，不会把整页撑高，也不会因笔记集过多而看不到下方。

**三栏折叠**（聚焦编辑）：视图底部浮动圆形按钮组 `‹ / ›` 渐进式收起/展开。顺序约束：必须先收起主题树栏，才能收起笔记集栏；折叠为会话内临时状态，不持久化，重启回到默认展开态。

### 2. 独立搜索视图

侧边栏第 4 项「搜索」。`Ctrl / Cmd + K` 唤起，输入即搜（250ms 防抖），跨「主题 › 笔记集 › 笔记」全文匹配标题、正文与笔记集描述。结果卡片含标题 / 路径 / 命中片段高亮，点击自动跳转并展开对应位置，`Enter` 跳首条。

### 3. 零散笔记

侧边栏「零散笔记」独立视图。手动新建、编辑、彻底删除；可「移动到笔记集」——用**两个联动下拉框**（先选目标主题，再在该主题下选笔记集）。

### 4. 回收站

侧边栏「回收站」独立视图。

- 删除笔记时可选「移入回收站」（保留最新 N 篇）或「变为零散笔记」。
- 设置中可配置保留数量（默认 30），超出自动清理。
- 恢复路径：①「恢复到零散笔记」一步到位；②「恢复到指定笔记集」两个联动下拉框。
- **笔记集整集回收**：删除笔记集时可选「将整个笔记集放入回收站（保留结构）」，整集作为一条 `type:'collection'` 回收项进入回收站（带「笔记集」徽标 + 左侧珊瑚色条）；恢复时选目标主题即还原为含全部笔记的新笔记集（重名自动加 `(恢复)` 后缀）。
- 永久删除、清空回收站。

> 删除**真正落盘**：回收站与零散笔记的清理改为始终执行写+清理，删除即时生效且重启后保持（修复早期「删除不生效、重启复活」问题）。

### 5. 设置（持久化）

设置面板含「通用」「工作区」两项：

- **通用**：外观（浅色 / 深色，重启保持）、回收站保留数量。
- **工作区**：查看/更改工作区位置、从工作区刷新（重新扫描本地文件并更新视图）。

所有设置经 `settings:save` IPC 写入 `.workspace.json` 并持久化，重启后保持。

### 6. Agent 集成（把工作目录交给 AI Agent）

NotePlanner 的工作目录可同时作为任意 Agent 的工作目录：Agent 在你的提问之外，按约定规则新建零散笔记或填充主题 / 笔记集 / 笔记。

- 规则文件位于 `workspace/AGENTS.md` 与 `workspace/noteplanner.rules.md`（YAML 块 + 自然语言）。
- 约定示例：让 Agent 生成笔记集骨架（如「马克思主义」笔记集 + 导论 / 马克思主义哲学 / 马克思主义政治经济学 / 科学社会主义 四篇空笔记）。
- **外部改动自动刷新**：主进程 `fs.watch` 监听工作区，`preload.js` 暴露 `onWorkspaceChanged` 桥；渲染进程收到后先 flush 待写编辑，再重扫并按当前视图刷新。
- **安全孤儿清理**：`sync()` 改为「按侧车判断归属」——任何 `.md` / 主题目录 / 笔记集目录**只要没有对应侧车文件**，就视为 Agent 新增内容、一律保留，绝不误删；只有「有侧车且已从模型移除 / 路径已变」的才会真正删除。这样 Agent 新建的内容不会被 NotePlanner 的同步逻辑清掉，而你在 UI 内的删除/重命名仍正确落盘。

## 使用指南

### 新建与组织

1. **主题**：在笔记集视图主题树内右键或操作按钮新建主题。
2. **笔记集**：在某主题下新建笔记集，可设颜色标记、描述。
3. **笔记**：在笔记集内新建笔记，用 Markdown 编辑，实时预览。

### 删除与恢复

- 删除笔记 → 弹窗二选一：移入回收站 / 变为零散笔记。
- 删除笔记集 → 三选项：删除并笔记进回收站 / 笔记转零散 / **整集放入回收站（保留结构）**。
- 回收站内按需恢复或永久删除。

### 搜索

`Ctrl / Cmd + K` 打开搜索，输入关键词，回车跳转首条结果。

### 移动零散笔记

在零散笔记视图点「移动到笔记集」，依次选主题、笔记集确认。

### 切换工作区

设置 → 工作区 → 更改，可选择是否把现有数据迁移到新路径。

## 项目结构

```
NotePlanner/
├── main.js              # Electron 主进程：窗口 / 文件 IO / IPC / 工作区扫描与同步
├── preload.js           # 安全桥接层（contextIsolation），向渲染进程暴露受控 API
├── app.js               # 渲染进程：UI 逻辑与交互
├── index.html           # 渲染进程骨架
├── styles.css           # 样式（珊瑚色主题、三栏布局、动效）
├── start.bat            # 一键启动（自动装 Electron）
├── package.json         # electron devDependency，npm start 启动
├── DESIGN.md            # 软件设计文档（结构、数据模型、功能模块、已知缺口）
└── workspace/           # 用户笔记数据（git 已忽略，不进仓库）
    ├── AGENTS.md              # Agent 集成指引
    └── noteplanner.rules.md   # Agent 写入规则（YAML 块 + 自然语言）
```

### 数据与配置边界

| 路径 | 是否进仓库 | 说明 |
|---|---|---|
| `workspace/` | 否（gitignore） | 你的笔记数据，完全本地、不共享 |
| `.workspace.json` | 否（gitignore） | 设置（主题 / 保留数 / 工作区路径） |
| `node_modules/` | 否（gitignore） | 依赖 |
| `.workbuddy/` | 否（gitignore） | 本地辅助数据 |
| 源码 / `DESIGN.md` / 启动脚本 | 是 | 应用本体 |

### 技术栈

- Electron 43 + 原生 JavaScript（无前端框架）。
- 主进程 `Node 22` 全局 `fetch` 调用文件系统；`fs.watch` 监听变更。
- 渲染进程三栏布局 + Markdown 实时预览。
- 笔记结构化元数据存于同名 `.meta.json` 侧车文件，不污染 `.md` 正文。
